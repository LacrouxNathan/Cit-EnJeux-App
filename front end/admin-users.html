Modifier un membre

Le CA peut gérer les fiches de jeux, mais pas les comptes ni le stock physique. Les administrateurs disposent des mêmes droits de gestion. Il doit toujours rester un administrateur actif ayant activé son compte.

La désactivation ferme les accès sans supprimer le compte ni ses historiques. La réactivation ne restaure pas les anciennes sessions. Un changement d’email ferme aussi les sessions ; pour un compte non activé, il faut renvoyer une invitation à la nouvelle adresse.
